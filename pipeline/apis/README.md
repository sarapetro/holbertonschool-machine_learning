# APIs

## Description

This project introduces Application Programming Interfaces (APIs) and how to interact with them using Python. It focuses on retrieving, processing, and manipulating data from external services through HTTP requests.

## Learning Objectives

- Understand what an API is and how it works.
- Understand the principles of REST APIs.
- Learn about HTTP methods (GET, POST, PUT, DELETE).
- Send HTTP requests using the Python `requests` library.
- Understand HTTP status codes and responses.
- Work with JSON data.
- Extract and manipulate data using Python dictionaries and lists.
- Handle API pagination.
- Use query parameters in API requests.
- Handle errors when communicating with APIs.

## Technologies Used

- Python 3.9
- REST APIs
- HTTP/HTTPS
- JSON
- Requests library

## Key Concepts

### REST API
A REST API allows applications to communicate over HTTP using standard methods.

### HTTP Methods
- GET: Retrieve data.
- POST: Create data.
- PUT: Update or replace data.
- DELETE: Remove data.

### JSON
JSON (JavaScript Object Notation) is a lightweight format used to exchange structured data between applications.

### API Pagination
Pagination divides large datasets into smaller pages, allowing applications to retrieve data efficiently.

### HTTP Status Codes
- 200: OK
- 201: Created
- 400: Bad Request
- 401: Unauthorized
- 404: Not Found
- 500: Internal Server Error
