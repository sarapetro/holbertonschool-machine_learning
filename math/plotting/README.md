
# Plotting with Matplotlib

## Description
This project introduces data visualization in Python using
Matplotlib and NumPy. It covers different types of graphs,
plot customization, and combining multiple plots.

## Requirements
- Python 3.9
- NumPy 1.25.2
- Matplotlib 3.8.3
- Ubuntu 20.04 LTS
- pycodestyle 2.11.1

## Tasks

### 0. Line Graph
Plot a cubic function using a solid red line.

### 1. Scatter Plot
Create a scatter plot showing men's height versus weight.

### 2. Change of Scale
Plot the exponential decay of Carbon-14 using a
logarithmic y-axis.

### 3. Two
Compare the exponential decay of C-14 and Ra-226
using two line graphs.

### 4. Frequency
Display student grades using a histogram.

### 5. All in One
Combine five different graphs into one figure
using subplots.

### 6. Stacking Bars
Create a stacked bar chart showing fruit quantities
for three people.
